Задача: портировать мод Immersive Weathering на Fabric для
Minecraft 26.1.2. Делаю для себя и друзей (одиночная игра и
мультиплеер), публиковать не планирую. Работай в текущей папке.

ИСХОДНИКИ
https://github.com/Silversmith-Mods/Immersive-Weathering
ветка 1.21.1 — внутри на самом деле версия 1.20.1-2.0.5
(Architectury, модули common/fabric/forge, ~186 Java-файлов,
parchment-маппинги, Moonlight Lib используется примерно в 36 файлах).
Лицензия мода LGPL-3.0 — сохрани LICENSE, ATTRIBUTIONS и указание
оригинальных авторов.

ЦЕЛЬ
- Только Fabric (Forge и Architectury убрать, сделать обычный
  Fabric-проект), Minecraft 26.1.2.
- Fabric Loader 0.19.3+, Fabric API 0.155.3+26.1.2 (эта версия
  стоит у меня в игре), актуальные Loom/Gradle для 26.1.2
  (новый плагин net.fabricmc.fabric-loom без ремапа), Java 25.
- С 26.1 игра не обфусцирована, Yarn/parchment больше не нужны —
  используй официальные имена Mojang. Опирайся на Fabric Docs
  (porting), Fabric-блог по 1.21.x и 26.1, NeoForge porting primers
  и пример мода Fabric для 26.1.

МУЛЬТИПЛЕЕР (важно!)
Мод должен работать не только в одиночке, но и в мультиплеере:
на выделенном Fabric-сервере 26.1.2 и в LAN. Мод ставится и на
сервер, и всем игрокам.
- Строго разделяй клиентский и серверный код: никаких клиентских
  классов (рендер, частицы, экраны, модели) в общем коде,
  клиентская часть — только через client entrypoint.
  Выделенный сервер не должен падать при запуске.
- Вся игровая логика (выветривание, рост, таяние и т.д.)
  выполняется на сервере, клиент только отображает.
- Если нужна синхронизация (эффекты, частицы, конфиг) — используй
  сетевые пакеты Fabric API (payloads) или ванильную синхронизацию
  блоков, а не клиентскую логику.
- Серверные настройки конфига должны применяться с сервера,
  а не у каждого игрока по-своему.

MOONLIGHT
Подключай Moonlight как готовую зависимость: версия
26.1.2-4.2.2 для Fabric (эта версия стоит у меня в игре; если на
Modrinth есть новее — скажи, я обновлю), официальная сборка через
maven Modrinth или CurseForge. Исходники для справки по API:
https://github.com/MehVahdJukaar/Moonlight/tree/26.1.2
ВАЖНО: у Moonlight своя лицензия (Supplementaries Team License),
которая запрещает копировать/переписывать её код, в том числе
с помощью ИИ. Не копируй и не портируй код Moonlight — только
вызывай её публичный API из Immersive Weathering. Если нужного
в новой версии Moonlight нет — напиши своё решение под задачу IW.
