# Fabric-сервер 26.1.2 с Immersive Weathering (для игры с друзьями)

Готовая папка сервера лежит в `C:\mods\iw-port\server\` (в git не входит):

```
server\
  fabric-server-launch.jar      лаунчер Fabric (loader 0.19.3, Minecraft 26.1.2)
  start.bat                     запуск
  mods\
    fabric-api-0.155.3+26.1.2.jar
    moonlight-26.1.2-4.2.2-fabric.jar
    immersive_weathering-26.1.2-2.0.5-port.1.jar
```

## Первый запуск
1. Нужна **Java 25** (у вас стоит Temurin 25).
2. Запустите `start.bat`. Первый запуск скачает сервер Minecraft и остановится: нужно принять EULA.
3. Откройте появившийся `eula.txt`, замените `eula=false` на `eula=true`
   (этим вы принимаете https://aka.ms/MinecraftEULA) и запустите `start.bat` ещё раз.
4. Когда в консоли появится `Done (...)! For help, type "help"` — сервер работает. Остановка: команда `stop`.

## Что поставить друзьям (клиент)
Minecraft 26.1.2 + Fabric Loader 0.19.3 или новее, в папку `mods` — **те же три файла**, что и на сервере:
Fabric API 0.155.3+26.1.2, Moonlight 26.1.2-4.2.2 (fabric), `immersive_weathering-26.1.2-2.0.5-port.1.jar`.
Без мода (или с другой версией) клиент не подключится: мод добавляет блоки и меняет ванильные.

Если у кого-то стоят моды с новыми деревьями, они должны стоять **у всех и на сервере**: для каждого типа
дерева мод регистрирует свою кучу листьев и кору, и набор блоков обязан совпадать.

## Как подключиться
- **Одна сеть (LAN)**: адрес `локальный-IP-сервера:25565` (узнать: `ipconfig`, строка IPv4).
  Вариант без сервера: в одиночной игре «Открыть для сети» — тоже работает, мод должен стоять у всех.
- **Через интернет**: либо пробросить порт TCP 25565 на роутере и дать друзьям внешний IP, либо
  использовать виртуальную сеть (у вас установлен ZeroTier — друзья подключаются к вашей сети ZeroTier
  и заходят по вашему ZeroTier-адресу и порту 25565).
- В брандмауэре Windows разрешите Java входящие подключения (система спросит при первом запуске).

## Настройки
- `server.properties` — обычные настройки сервера (`max-players`, `difficulty`, `white-list` и т.д.).
  Если играете только со своими, включите белый список: `white-list=true` и в консоли `whitelist add Ник`.
- Память: в `start.bat` параметр `-Xmx4G` (4 ГБ). Для 2–5 игроков достаточно.
- **Настройки мода**: `config\immersive_weathering-common.json` на сервере. Это серверный конфиг —
  значения применяются на сервере и отправляются всем игрокам при входе, у каждого по-своему быть не может.
  Клиентские (частицы листвы, звук распада) — у каждого игрока в `immersive_weathering-client.json`.
- Случайные тики (скорость выветривания, роста мха, ржавчины) зависят от правила `random_tick_speed`.

## Обновление мода
Пересоберите (`gradlew build` в `C:\mods\iw-port`), скопируйте новый jar из `build\libs\` в `server\mods\`
и раздайте его друзьям. Старый jar из `mods` удалите.

## Если что-то сломалось
Пришлите `server\logs\latest.log` (сервер) или `.minecraft\logs\latest.log` и файл из `crash-reports\` (клиент).
